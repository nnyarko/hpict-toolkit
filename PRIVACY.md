# Privacy: what HPI-CT does and does not collect

HPI-CT is used by privacy-sensitive compliance and government teams. Trust is the point, so this is plain and short.

## The toolkit itself

- **It runs entirely in your browser, offline.** Open the HTML file and it works with **no network connection**. Nothing about your assessment (your answers, your scores, your organization) ever leaves your device.
- **No accounts, no logins, no cookies, no third-party trackers, no analytics** are embedded in the offline toolkit file.
- If your browser saves progress, it uses local browser storage **on your machine only**; it is never transmitted.

## What we *can* see (aggregate, anonymous, no personal or assessment data)

We measure adoption only through signals that carry no identity and no assessment content:

- **GitHub**: public stars, forks, and repository/traffic and release-download counts GitHub provides to the maintainer. These are counts, not identities.
- **Zenodo**: download/view counts for the archived release (via the DOI).
- **Hosted version (if you use the online copy)**: the maintainer may run a **cookieless, privacy-respecting analytics** tool (e.g., Plausible / GoatCounter / Cloudflare Web Analytics) that records anonymous, aggregate page visits and country, **no cookies, no IP storage, no personal data, no assessment data.** The downloaded/offline copy has none of this.

## Optional, only if you choose

- **Update checks.** The toolkit does not check for updates and never contacts the project. If a future version adds an opt-in check, this page will describe it before that version is released.
- **Update list / testimonial / feedback**: if you email us, open an Issue/Discussion, or fill in an optional form, we keep only what you send us, for that purpose.

## What we never do

- We never collect PHI, claim-level data, beneficiary/provider identifiers, or your assessment responses.
- We never sell or share anything, and there is nothing personal to sell.
